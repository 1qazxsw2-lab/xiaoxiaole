# XiaoXiaoLe · UI 视觉圣经（精简版）

> 适用：Cocos Creator 3.8 + TypeScript，Web/H5 试玩广告（portrait，设计分辨率 **720×1280**）
> 现状：仅有 6×7 棋盘（4 色方块）+ 一个分数 Label，**无任何菜单 / 暂停 / 结算界面**。
> 本文档为新增三屏（主菜单 / 暂停 / 结算）定义视觉规范，所有色值已与现有方块色协调。
> 配套文档：`score-float-spec.md`（得分飘字特效）。

---

## 1. 视觉锚点（Visual Anchor）

- **品类基调**：休闲三消（match-3），轻快、糖果感、明亮、低门槛，面向移动端泛用户（试玩广告落地页）。
- **情绪关键词**：欢乐、爽快、奖励感、清爽。
- **设计目标**：在 3–5 秒试玩广告内让玩家一眼看懂"点点消除得分"；界面不抢棋盘风头，但要有清晰的"开始 / 继续 / 过关"引导。
- **美术风格**：扁平 + 轻度体积感（按钮用上亮下暗的胶囊感，不写实）。

---

## 2. 风格参照（Style Reference）

- 参考方向：Candy Crush（深紫背景 + 高饱和糖果块）、Toon Blast（圆润胶囊按钮 + 奶油卡片）。
- **与现有方块的关系**：棋盘 4 色是满饱和原色（见 §3 备注），UI **不**用满饱和原色铺大面积（会刺眼、互相打架），而是"从方块色派生出的柔化色 + 深紫底色"，让彩色方块在暗背景上自然跳出来。

---

## 3. 配色方案（Color Palette）

### 3.1 现有方块色（不可改，来自 `GridView.ts` 的 `colorMap`，非 ConstValue）

| 语义 | CellType | 工程色值 (Color) | 十六进制 |
|------|----------|------------------|----------|
| 红块 | RED | (255,0,0) | `#FF0000` |
| 绿块 | GREEN | (0,255,0) | `#00FF00` |
| 蓝块 | BLUE | (0,0,255) | `#0000FF` |
| 黄块 | YELLOW | (255,255,0) | `#FFFF00` |

> ⚠️ 这四个是 **100% 饱和原色**，直接用于界面会非常刺眼。**UI 一律使用下方"派生柔化色"，仅在图标/高光小面积呼应方块原色。**

### 3.2 UI 派生色板（协调原则：每个 UI 色都能在 4 色里找到"亲本"）

| 用途 | 名称 | 十六进制 | 派生自 | 说明 |
|------|------|----------|--------|------|
| 背景渐变·上 | `BG_TOP` | `#241A5C` | BLUE（加深+偏紫） | 深靛蓝，托住亮块 |
| 背景渐变·下 | `BG_BOTTOM` | `#4B2E83` | BLUE+紫 | 紫罗兰，增加层次 |
| 棋盘背板 | `BOARD_FRAME` | `#1A1240` | BLUE（更深） | 棋盘外框/底 |
| 棋盘网格线 | `GRID_LINE` | `#FFFFFF` @ 8% | — | 极淡白线分隔 |
| 卡片面板 | `PANEL_FILL` | `#FFF6E9` | —（暖奶油） | 菜单卡片底，保证可读性 |
| 卡片面板·白 | `PANEL_FILL_ALT` | `#FFFFFF` | — | 次级面板 |
| 遮罩 | `OVERLAY` | `#000000` @ 55% | — | 暂停/结算半透明黑 |
| 主文字(深底) | `TEXT_ON_DARK` | `#FFFFFF` | — | 深背景上的文字 |
| 主文字(面板) | `TEXT_ON_PANEL` | `#2B1E5E` | BLUE（深） | 奶油卡上的深紫字 |
| 次文字 | `TEXT_SECONDARY` | `#7A7099` | — | 说明/小字 |
| **主按钮(CTA)** | `BTN_PRIMARY` | `#FF5370` | **RED**（柔化珊瑚） | 主要操作，能量感 |
| 主按钮·按压 | `BTN_PRIMARY_PRESS` | `#D83A57` | RED | 按下变深 |
| 主按钮·高光 | `BTN_PRIMARY_TOP` | `#FF7A8F` | RED | 顶部高光渐变 |
| 次按钮 | `BTN_SECONDARY` | `#4D8BFF` | **BLUE**（柔化） | 次要操作 |
| 次按钮·按压 | `BTN_SECONDARY_PRESS` | `#3A6FD6` | BLUE | 按下变深 |
| 高光/星/分 | `ACCENT_GOLD` | `#FFD23F` | **YELLOW**（柔化） | 星星、金币、得分强调 |
| 胜利强调 | `WIN_GREEN` | `#2ECC71` | **GREEN**（柔化） | 过关绿 |
| 失败强调 | `LOSE_RED` | `#FF5370` | **RED**（柔化） | 失败红（同 CTA） |

**协调原则（核心）**：
1. 背景统一取 **BLUE 的深紫派生**，形成"暗舞台"，使 `#FF0000/#00FF00/#0000FF/#FFFF00` 四色块自然跳脱。
2. **正向/奖励 = 绿系**（`WIN_GREEN` ← GREEN），**负向/警示 = 红系**（`LOSE_RED`/`BTN_PRIMARY` ← RED）——与玩家对红绿块的直觉一致。
3. **CTA 用柔化红珊瑚**而非纯 `#FF0000`：保留红色的能量感，但去掉刺眼感，且不与棋盘红块"撞色到无法区分层级"。
4. **金/黄仅作小面积高光**（星星、分数前缀、按钮描边），呼应 YELLOW 而不喧宾夺主。
5. 文字在奶油卡上用深紫 `#2B1E5E`（源于 BLUE），对比度 ≥ 7:1，满足可访问性。

## 4. 构图与布局（三屏草图）

> 安全区：竖屏 720×1280，顶部留 8%（≈100px）给状态/分数，底部留 6%（≈80px）防手势条遮挡。所有面板居中，左右留 8%（≈58px）。

### 4.1 主菜单（Main Menu）

```
┌─────────────────────────────┐ ← 背景渐变 BG_TOP→BG_BOTTOM
│                             │
│        ★ XiaoXiaoLe ★       │ ← 72px LOGO，ACCENT_GOLD 描边
│         三消小冒险            │ ← 28px 副标题，TEXT_ON_DARK 奶油
│                             │
│      ┌───────────────┐      │
│      │   ▶ 开始游戏   │      │ ← 主按钮 圆角24 BTN_PRIMARY
│      └───────────────┘      │
│                             │
│      ┌───────────────┐      │
│      │   玩法说明     │      │ ← 次按钮 圆角24 BTN_SECONDARY
│      └───────────────┘      │
│                             │
│      最高分  1280            │ ← 22px 小字 ACCENT_GOLD + 白
│                             │
└─────────────────────────────┘
```
- 纵向居中堆叠，主按钮在最显眼的中上区。

### 4.2 暂停（Pause）

```
┌─────────────────────────────┐
│  (棋盘冻结，盖 OVERLAY 55%)  │
│      ┌───────────────┐      │
│      │     暂停        │      │ ← 52px 标题 TEXT_ON_PANEL
│      │ ─────────────  │      │ ← 分割线 8%灰
│      │  ▶ 继续游戏     │      │ ← 主按钮 BTN_PRIMARY
│      │  ↻ 重新开始     │      │ ← 次按钮 BTN_SECONDARY
│      │  ≡ 返回主菜单   │      │ ← 描边按钮（无色填充+紫描边）
│      └───────────────┘      │ ← PANEL_FILL 奶油卡，圆角28
└─────────────────────────────┘
```
- 半透明遮罩下保留棋盘模糊感；面板为奶油卡片，强对比引导操作。
- 顶栏分数在暂停时仍可见（遮罩不盖顶栏，或面板下方单独显示当前分）。

### 4.3 结算（Win / Lose）

**胜利：**
```
┌─────────────────────────────┐
│      ☀ 过关! ☀              │ ← 52px 标题 WIN_GREEN
│      ┌───────────────┐      │
│      │  最终得分       │      │ ← 22px 标签 TEXT_SECONDARY
│      │    1280        │      │ ← 64px 数字 ACCENT_GOLD
│      │  ★ ★ ★         │      │ ← 3 星 ACCENT_GOLD
│      └───────────────┘      │
│      ┌───────────────┐      │
│      │  下一关 ▶      │      │ ← 主按钮 WIN_GREEN
│      └───────────────┘      │
│      ┌───────────────┐      │
│      │   重玩          │      │ ← 次按钮 BTN_SECONDARY
│      └───────────────┘      │
└─────────────────────────────┘
```

**失败：**
```
┌─────────────────────────────┐
│      ✕ 挑战失败 ✕           │ ← 52px 标题 LOSE_RED
│      ┌───────────────┐      │
│      │  最终得分       │      │
│      │     320        │      │ ← 64px 数字 ACCENT_GOLD
│      │  ☆ ☆ ☆ (暗)    │      │ ← 星标置灰 #B9B2C9
│      └───────────────┘      │
│      ┌───────────────┐      │
│      │  再试一次      │      │ ← 主按钮 BTN_PRIMARY(LOSE_RED)
│      └───────────────┘      │
│      ┌───────────────┐      │
│      │  返回主菜单    │      │ ← 次按钮 描边
│      └───────────────┘      │
└─────────────────────────────┘
```
- 胜/负共用同一套布局骨架，仅**标题文案 + 强调色（绿/红）+ 星标状态**切换，降低实现成本、保持视觉一致。

## 5. UI 视觉语言（按钮 / 面板 / 图标）

### 5.1 按钮风格
- **形状**：圆角矩形，圆角半径 **24px**（大按钮）/ **16px**（小按钮）；比例建议高≈96px、宽≈360px（主）、≈280px（次）。
- **填充**：上亮下暗双色胶囊（顶部 `BTN_PRIMARY_TOP` → 底部 `BTN_PRIMARY`），制造轻度"立体糖果"体积感。
- **描边**：外描边 2px 白色 @ 30%，提升在彩色背景上的边界清晰度。
- **文字**：居中，`TEXT_ON_DARK`（白）34px 粗体，字距 +1。
- **按压态（Press）**：
  - 缩放 `scale` → **0.94**（用 Button 的 `Transition = SCALE` 即可）；
  - 填充切换为 `BTN_PRIMARY_PRESS`（变深）营造"按下"；
  - 轻微下移 2px（可选，增强按压感）。
- **禁用态**：填充降到 40% 不透明度 + 文字 60% 灰，明确不可点。
- **零资源实现**：用 `Graphics` 在运行时绘制圆角矩形背景（无需贴图），或用 1 张白色 9-slice 圆角贴图 `tint` 复用。推荐 `Graphics` 以彻底零依赖。

### 5.2 面板（卡片）
- 奶油卡 `PANEL_FILL` `#FFF6E9`，圆角 **28px**，外描边 2px `#FFFFFF`@30%，投影 `OVERLAY`@20% 偏移(0,8) 模糊 16（用 Sprite+mask 或 Graphics 模拟）。
- 面板内边距 ≥ 40px。

### 5.3 图标
- 用 Unicode/内置字符（▶ ↻ ≡ ★ ☀ ✕）或极简 `Graphics` 图形，**不引入图标字体/图片**，保证 H5 秒开。
- 星标 ★ 用 `ACCENT_GOLD`；未点亮用 `#B9B2C9`。

## 6. 字体与字号（Typography）

- **字体家族（移动端 H5，零外部字体，秒加载）**：
  ```
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Yuanti SC", sans-serif
  ```
  - iOS/macOS 优先圆体 `Yuanti SC` 增可爱感；无则用系统黑体兜底。
  - **不引入自定义 .ttf**（试玩广告对首屏体积敏感）。
- **字重**：标题/数字用 **Bold（700）**，正文 Regular。
- **设计分辨率 720×1280 下推荐字号**：

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 主菜单 LOGO | 72px | Bold | ACCENT_GOLD 描边 |
| 主菜单副标题 | 28px | Regular | TEXT_ON_DARK |
| HUD 分数值 | 44px | Bold | ACCENT_GOLD |
| HUD "SCORE" 标签 | 22px | Regular | TEXT_ON_DARK |
| 屏标题（暂停/结算） | 52px | Bold | 深紫/绿/红 |
| 结算最终分数 | 64px | Bold | ACCENT_GOLD |
| 按钮文字 | 34px | Bold | 白 |
| 正文/说明 | 26px | Regular | TEXT_SECONDARY |
| 飘字（见飘字文档） | 40–48px | Bold | 白+深紫描边 |

## 7. 动画原则（Animation Principles）

- **入场**：面板/按钮从下方 `y -40` + `opacity 0→255`，时长 **0.3s**，`easing: backOut`（轻微回弹，活泼）。
- **退场**：上移 `y +30` + `opacity→0`，时长 **0.2s**，`easing: quadIn`。
- **按钮按压**：见 §5.1（scale 0.94 + 变深）。
- **星级点亮**：结算时星星依次 `scale 0→1.2→1` 错峰 0.1s 弹出，`easing: backOut`。
- **基调**：所有 UI 动画 ≤ 0.4s，避免拖沓；缓动统一用 `backOut`（弹）/`quadOut`（顺滑），与棋盘消除的 `toDie` 缩放消失（见 `CellView.ts`）保持同一"Q 弹"手感。

## 8. 资产命名与预算（Asset Naming & Budget）

- **目标**：本 UI 方案 **零外部贴图/字体依赖**（全部 `Graphics`/系统字体/字符图标），故资产清单极简：
  - `textures/ui/round_rect_white.png`（可选 9-slice，若不用 Graphics）——9×9 白圆角，tint 复用。
  - 无音频（沿用现有 `AudioManager`）。
- **命名规范**：`类型_用途_状态`，如 `btn_primary_normal` / `panel_card` / `icon_star_on`。
- **预算**：H5 试玩广告总包体建议 ≤ 4MB；UI 纹理占用应 < 200KB（单张圆角白图 < 5KB）。
- **坐标系**：所有 UI 节点挂在 **Canvas（UI 相机）** 下，设计分辨率 720×1280，适配 `FIT_HEIGHT` 或 `SHOW_ALL`。

## 9. 可访问性 & 与方块配色衔接（Accessibility & Coordination）

- **对比度**：面板文字 `TEXT_ON_PANEL #2B1E5E` 对 `PANEL_FILL #FFF6E9` 对比度 ≈ 9:1，达 WCAG AA/AAA；深底文字用纯白。
- **可点击区域**：按钮最小命中区 ≥ **80×80px**（H5 触控友好），视觉尺寸可更小但命中区放大。
- **色盲友好**：**不单独依赖红/绿传递胜负**——胜/负除颜色外还有文案（过关!/挑战失败）与图标（☀/✕）区分。
- **与方块衔接的硬规则**：
  1. 界面大面积只用 §3.2 派生色，**绝不**直接铺 `#FF0000/#00FF00/#0000FF/#FFFF00`。
  2. 红=行动/负向、绿=正向、黄=奖励高光、蓝=背景与次操作——语义与方块直觉一致。
  3. 新增任何 UI 元素配色，必须能在 §3.2 色板中找到亲本；如需新色，先回美术确认。
